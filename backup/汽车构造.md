## 一、名词解释汇总

| ---- | -------------------- | ------------------------------------------------------------ |

## 三、功用汇总

- 1. | 部件/系统                        | 功用                                                         |
     | -------------------------------- | ------------------------------------------------------------ |
     | **离合器**                       | 1. **保证汽车平稳起步**：起步时主从动部分通过滑磨，转速逐渐接近，确保起步平稳；<br>2. **保证变速器换挡工作平顺**：换挡时分离切断动力传递，减轻齿轮齿间冲击；<br>3. **防止传动系统过载**：转矩超过最大传递转矩时主从动部分滑磨，防止过载 |
     | **变速器**                       | 1. 改变传动比，扩大驱动轮转矩和转速的变化范围，适应行驶条件变化；<br>2. 在发动机旋转方向不变前提下，使汽车能倒退行驶；<br>3. 利用空挡，中断动力传递，便于启动怠速、换挡或动力输出 |
     | **同步器**                       | 使接合套与待啮合齿圈迅速同步，缩短换挡时间，防止啮合时产生结合齿之间的冲击 |
     | **液力变矩器**                   | 起到离合器的作用，传递或切断发动机与自动变速器传动机构之间的动力。<br/>在一定范围内变速变扭。<br/>起到飞轮的作用，使发动机运转平稳。<br/>缓冲发动机脱动带来的冲击振动。<br/>驱动液压控制系统的油泵运转 |
     | **万向传动装置**                 | 实现一对轴线相交且相对位置经常变化的转轴之间的动力传递       |
     | **驱动桥**                       | 1. 将万向传动装置传来的发动机转矩通过主减速器、差速器、半轴等传到驱动车轮，实现降低转速、增大转矩；<br>2. 通过主减速器锥齿轮副改变转矩的传递方向；<br>3. 通过差速器实现两侧车轮的差速作用，保证内外侧车轮以不同转速转向；<br />4. 通过桥壳和车轮实现承载和传递 |
     | **主减速器**                     | 将输入的转矩增大并相应降低转速，发动机纵置时还具有改变转矩旋转方向的作用 |
     | **差速器**                       | 汽车转弯或在不平路面上行驶时，使左右驱动车轮以不同的角速度滚动，保证两侧驱动轮与地面间做纯滚动运动 |
     | **车架**                         | 支撑连接汽车的各零部件，并承受来自车内外的各种载荷           |
     | **车桥**                         | 传递车架与车轮之间各方向的作用力以及其力矩                   |
     | **悬架**                         | 把路面作用于车轮上的垂直反力、纵向反力和侧向反力，以及这些反力所造成的力矩传递到车架上，以保证汽车的正常行驶 |
     | **轮胎**                         | 1.与汽车悬架一起用来缓和汽车行驶时所受到的冲击，并衰减由此而产生的振动，以保证汽车有良好的乘坐舒适性和行驶平顺性。<br />2.保证车轮和路面有良好的附着性，以提高汽车的牵引性、制动性和通过性<br />3.承受汽车的重力，并传递其他方向的力和力矩 |
     | **弹性元件**,减震器,**导向机构** | **弹性元件**(缓冲)承受并传递路面作用于车轮上的垂直载荷，缓和不平路面传给车架（或车身）的冲击力，保证汽车行驶平顺性。常见形式有钢板弹簧、螺旋弹簧、扭杆弹簧、空气弹簧等。<br />**减震器**（减震）与弹性元件并联作用，加速衰减车架（或车身）与车桥（车轮）之间因路面冲击引起的振动，改善汽车的行驶平顺性，并提高轮胎与路面的附着性，保证操纵稳定性。<br />**导向机构**（导向）用以传递除垂直力以外的各种力和力矩（如纵向力、侧向力及其力矩），并确保车轮按照一定轨迹相对车架（车身）跳动，保证汽车的正确行驶方向和操纵稳定性。 |
     | **汽车转向系统**                 | 保证汽车能按驾驶人的意志而进行转向行驶                       |
     | **电动助力转向系统**             | 保证汽车在低速转向行驶时轻便灵活，高速转向行驶时稳定可靠     |
     | **汽车制动系统**                 | 使行驶中的汽车减速甚至停车，使下坡行驶的汽车速度保持稳定，以及使已停驶的汽车保持不动 |
     | **汽车行驶系统**                 | 1)接受由发动机经传动系统传来的转矩，并通过驱动轮与路面间的附着作用，产生路面对驱动轮的驱动力，以保证汽车正常行驶。<br/>2)传递并承受路面作用于车轮上的各向反力及其所形成的力矩，<br/>3)尽可能缓和不平路面对车身造成的冲击，并衰减其振动，以保证汽车行驶平顺性。<br />4)与汽车转向系统协调配合工作，实现汽车行驶方向的正确控制，以保证汽车操纵稳定性。 |

     

## 四、简答

### 1.在保证可靠传递动力最大转矩的前提下，离合器的具体结构应能满足主层的部分什么?
1.分离彻底，接合柔和
2.从动部分的转动惯量要尽量可能小
3.散热良好
4.操纵轻便
5.具有良好的动平衡

### 2.为保证变速器在任何情况下都能准确安全可靠的工作，对变速器操纵机构提出如下要求：
1.保证变速器不自行脱挡或挂挡，在操纵机构中应设有自锁装置。
2.保证变速器不同时挂入两个档位，在操纵机构内应设互锁装置。
3.防止误挂倒挡，在变速器操纵机构中应设有倒档锁

### 3. 离合器的工作过程原理

**接合状态**：依靠压紧弹簧弹力，将压盘压紧从动盘，使从动盘夹紧在飞轮与压盘之间，靠摩擦力传递发动机转矩。

**分离过程**：踩下踏板→分离轴承推动分离杠杆→压盘后移→从动盘与飞轮、压盘分开→摩擦联系切断→动力中断。

**接合过程**：松开踏板→压紧弹簧弹力释放→压盘逐渐压紧从动盘→主从动部分转速不同产生滑磨→摩擦力矩逐渐增大→转速趋于一致→完全接合，动力恢复传递。
### 4.变矩系数

液力变矩器**输出转矩 $M_w$**（涡轮转矩）与**输入转矩 $M_b$**（泵轮转矩）之比，称为**变矩系数**，用 $K$ 表示。

公式：**$$K = \dfrac{M_w}{M_b}$$**


### 5.要实现等速所需条件：

1.第万向节两轴间的夹角a1与第二万向节两轴间的夹角a2相等;
2.第一万向节从动叉2与第二万向节主动叉3 处于同一平面内.

### 6.转向轮定位参数——四个角的概念

| 参数               | 概念                                                         |
| ------------------ | ------------------------------------------------------------ |
| **主销后倾角**     | 主销轴线在汽车纵向平面内的投影线与垂直线之间的夹角。其作用是使转向轮具有自动回正能力。 |
| **主销内倾角**     | 主销轴线在汽车横向平面内的投影线与垂直线之间的夹角。其作用是使转向轮转向后能自动回正，并减小转向力。 |
| **前轮外倾角**     | 车轮中心平面与垂直线在汽车横向平面内的夹角（车轮上部向外倾斜）。其作用是减小车轮的滚动阻力，防止车轮内倾，提高行驶安全性。 |
| **前轮前束（角）** | 两前轮中心平面之间的夹角（或前后端轮距差所形成的角度），通常表现为两轮前端间距小于后端间距。其作用是抵消因车轮外倾而产生的滚动偏离趋势，防止轮胎过度磨损。 |

### 7,ABS的好处

1. **能够根据汽车的行驶状态和车轮转动情况**，在制动过程中自动调节车轮制动力，**提高行车安全性**。
2. **改善汽车制动时的方向稳定性**。
3. **缩短制动距离**。
4. **增加汽车制动时的轮胎（与地面的）附着力**。
5. **减少轮胎磨损**。
### 8.发动机传动系统5个公用有哪些部件？
增速增距的是变速器和主减速器。
汽车变速的是变速器。
汽车倒驶的是变速器
必要时中断传动系统的动力传递的是离合器
因式两侧驱动车轮，具有差速作用的是差速器
