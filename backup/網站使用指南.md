這個網站的文章，會按**標籤**換成不同的版面：周記像一本紙本雜誌，隨筆像夜裡的手稿，學習像筆記本，AI 是提示詞工作台，教程和說明書是工程手冊。這篇說明每種版面怎麼讀、怎麼寫。

## 一覽

| 標籤 | 版面 | 適合寫什麼 | Loon |
|---|---|---|---|
| `weekly` | 周記雜誌 | 每週的記錄、長文隨想 | 不出現 |
| `ai` | 提示詞工作台 | 提示詞、AI 用法 | 出現 |
| `study` | 夜間筆記本 | 學習筆記、知識整理 | 出現 |
| `Doc` | 說明書 | 查找用的說明、規格、參考表 | 出現 |
| `Guidebook` | 教程 | 一步一步照著做的教學 | 出現 |
| `growth` | 夜讀手稿・成長 | 階段回顧、這個月學會了什麼 | 出現 |
| `musings` | 夜讀手稿 | 隨筆、散文 | 出現 |
| 其他 | 原本的閱讀頁 | — | 出現 |

一篇文章貼了好幾個標籤時，**按上表從上往下取第一個**。例如同時貼 `Doc` 和 `Guidebook`，用說明書版面。

下面這幾個標籤是網站的開關，不是分類：

- `Journal`：變成「短札」，不出現在文章列表。
- `pinned`：置頂。
- `chronicle-data`、`timeline`：編年史用的資料。

## 所有文章頁都有的

- **Loon**：螢幕寬度 1180px 以上、用滑鼠時，坐在左下角。點她會說話，長按會說一句名言；不同版面她說的話不一樣。周記頁沒有她。
- **評論**：在文章最後，用 GitHub 帳號登入就能留言。
- **背景圖**：只有沒貼上表標籤的普通文章，才能在目錄裡換背景圖；其他版面有自己的樣子，不顯示背景圖。

## 周記 `weekly`：雜誌版

像一本安靜的紙本雜誌。網站是淺色外觀時用白紙，其他外觀用夜間紙張；星空、Loon、唱片播放器都會收起來，只留下字。

**怎麼讀**

- 標題上方是「WEEKLY · 第 N 期」。期號按發布順序自動算：最早的一篇周記是第 1 期。
- 底部一條狀態列：左邊「目錄」，中間是閱讀進度，右邊是剩餘時間和百分比。
- 點「目錄」從左側滑出章節列表，目前章節標紅。按 `Esc` 或點暗處關閉。
- 文章最後是「上一期／下一期」，只在周記之間跳。

**怎麼寫**

| 效果 | 寫法 |
|---|---|
| 首字放大 | 自動：正文第一段（至少 20 字） |
| 大字金句（上下有線框） | 單獨一段、90 字以內的引用 |
| 圖說 | 圖片的替代文字 |
| 結尾小方塊 | 自動：最後一段末尾 |

```markdown
> 好的版面不會讓你注意到它。

![夜裡的路燈](https://圖片網址)
```

章節標題用 `#` 或 `##` 都可以，不需要自己編號。

## 隨筆 `musings`、成長 `growth`：夜讀手稿

星空會調暗，標題置中，下面有一筆金色的手繪線，讀起來慢一點。

**怎麼讀**

- 文中的金句是置中的金色字。
- Loon 過一會兒會念出文中的一句金句；讀到最後，她會說一句晚安。點她會再念一次。
- **成長**多一行金色手寫的季節（Spring、Summer、Autumn、Winter），還有「第 N 週」，都按發布日期自動算。

**怎麼寫**

| 效果 | 寫法 |
|---|---|
| 金色金句 | 單獨一段、90 字以內的引用 |
| 小金葉分隔 | `---` |
| 結尾署名 | 自動：隨筆是「— Luliy」，成長是「to be continued」 |

```markdown
> 人走在燈與燈之間，其實一直都在光裡。

---
```

成長的標籤寫 `growth`、`成长` 或 `成長` 都可以。

## 學習 `study`：夜間筆記本

正文像寫在方格紙上，左邊有一條紅色頁邊線。

**怎麼讀**

- 用淡金色螢光筆劃過的是重點。
- 彩色框分四種：筆記、例子、重點、注意。
- 註解在螢幕夠寬時出現在右邊頁邊，不用跳到文末找。
- 文章最後是「本篇要點」，按「開始複習」會出抽認卡，可以選「記得」或「再看一次」。
- 點 Loon，她會一條一條念要點。

**怎麼寫**

| 效果 | 寫法 |
|---|---|
| 螢光筆，並收進「本篇要點」 | `**粗體**`（兩句以上才出現要點，最多 8 句） |
| 筆記框 | `> [!NOTE]` |
| 例子框 | `> [!TIP]` |
| 重點框 | `> [!IMPORTANT]` |
| 注意框 | `> [!WARNING]` 或 `> [!CAUTION]` |
| 頁邊註 | 正文寫 `[^1]`，文末寫 `[^1]: 註解內容` |

```markdown
它說的不是程式跑幾秒，而是**資料變多時，時間怎麼增長**[^1]。

> [!IMPORTANT]
> 時間複雜度：演算法步驟數的增長量級。

[^1]: 秒數會受電腦快慢影響，所以只看增長的趨勢。
```

## AI `ai`：提示詞工作台

**怎麼讀**

- 提示詞是一張張卡片。黃色的格子可以直接填，例如書名、時間。
- 按「複製提示詞」，複製出來的就是你填好的版本，貼到任何 AI 都能用；沒填的格子會保留原樣。
- 點 Loon，她會列出這篇有哪些提示詞。

**怎麼寫**

把提示詞放在程式碼區塊裡，語言寫 `prompt`；要讓讀者填的地方寫成 `{{名稱}}`。卡片標題會自動取它上面最近的小標題。

````markdown
## 三層摘要

```prompt
請幫我整理《{{書名}}》的重點，分三層：
1. 一句話說出這本書在講什麼
2. 我可以在 {{時間}} 開始實踐的 {{數量}} 個行動
```
````

只要內容裡有 `{{名稱}}`，不寫 `prompt` 也會變成卡片。普通的程式碼區塊不受影響。

## 教程 `Guidebook`：工程手冊・步驟版

給「照著做」的文章。

**怎麼讀**

- 開頭的任務卡寫著預計時間、步驟數，以及開始前需要準備什麼。
- 每個大標題是一步：`STEP 01`、`STEP 02`……左邊有一條線把它們串起來。
- 做完一步，按這一步末尾的「標記完成」，或按鍵盤 `x`。完成的步驟會變暗，右側目錄打勾，進度條往前走。下次回來進度還在，但只記在你自己的瀏覽器裡。
- 右側目錄常駐；手機上點右下角 ☰ 打開。
- 全部完成時，Loon 會恭喜你。

**怎麼寫**

- 每一步用最上層的標題（通常是 `#`），小步驟用下一層。
- 標題可以自己寫編號（`1.`、`一、`），網站會換成 STEP 編號。
- 「簡介、前言、目錄、常見問題、參考、附錄、總結、細節」這類標題不算步驟。
- 開頭第一個清單會當成「開始前需要」。

```markdown
# 簡介
這篇教你用 Gmeek 搭一個部落格。

# 1. 建立倉庫
## 1.1 用模板建立

# 2. 設定網域
```

## 說明書 `Doc`：工程手冊・查找版

給「回頭查」的文章。

**怎麼讀**

- 頂部是 `DOC(7)` 式的頁首，下面寫著最後修訂日期。
- 章節自動編號為 1、1.1、1.2……方便指認。
- 滑鼠移到標題上，左邊會出現 `#`，點一下就複製這一節的連結。
- 右側目錄常駐，頂部有搜尋框：按 `/` 開始打字，只留下符合的章節，命中的字會高亮；按 `Esc` 清空。
- 表格用等寬字的表頭，隔行有淡淡的底色，方便橫著看。

**怎麼寫**

- 用 `##` 和 `###` 分層。標題已經有編號的，網站不會重複加。
- 參數、模組這類資料，用表格寫最好查。

## 鍵盤快捷鍵

教程和說明書都可以用：

| 按鍵 | 作用 |
|---|---|
| `j` / `k` | 下一節／上一節 |
| `x` | 勾選目前這一步（教程） |
| `/` | 搜尋本文（說明書） |
| `g` `g` / `G` | 到頂部／到底部 |
| `?` | 顯示快捷鍵說明 |
| `Esc` | 關閉 |

在輸入框裡打字時，這些按鍵不會觸發。

## 常見問題

**貼了標籤，版面沒變？**
標籤要貼在 Blog A。貼好後要等部落格重新生成，大約幾分鐘；還沒變的話，重新整理一兩次。

**周記的期號變了？**
期號按發布順序算。刪掉一篇、補發一篇舊的，或者把舊文章改貼 `weekly`，後面的期號都會跟著變。

**提示框沒有變色？**
第一行要寫成 `> [!NOTE]` 這種格式，大小寫都可以。

**頁邊註跑到文末了？**
右邊空間不夠，或是在手機上時，註解會留在文末，這是正常的。

**勾過的步驟、讀者的設定存在哪？**
只存在讀者自己的瀏覽器裡。換裝置、清除瀏覽資料就會重來。
